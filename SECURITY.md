# Security reporting

Please report potential vulnerabilities privately to
[support@datanamix.com](mailto:support@datanamix.com). Include the SDK
platform and version, reader model, supported OS/browser version, a concise
reproduction, and the security impact. Do not post exploits or sensitive
details in a public issue before coordination.

Do **not** send fingerprints, WSQ files, API credentials, identity documents,
customer records, raw USB payloads, or private diagnostic logs. If more detail
is needed, Datanamix support will arrange an appropriate private channel.

This repository currently has no customer-ready release. Security fixes and
support commitments will be stated with each approved version.
